# skerjanc.org

Website of **HyperWare Solutions, Nejc Škerjanc, s.p.** — custom software engineering, Kranj, Slovenia.

Static site (HTML/CSS/JS, no build step), hosted on GitHub Pages at https://skerjanc.org.

- `index.html` — page structure and English text (default language)
- `i18n.js` — Slovenian translations and language switch
- `styles.css`, `script.js` — styling and behaviour
- `CNAME` — custom domain for GitHub Pages
